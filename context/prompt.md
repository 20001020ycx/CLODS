1. **Workspace.** You own exactly one folder, `evaluations/<system>/<bug id>/`. Create it

3. **Commit & push after EVERY milestone.** Right after a milestone is `DONE` (or
   `FAILED`): `git pull --rebase origin main`, then `git add evaluations/<system>/<bug id>`
   (your folder only — never `git add -A`), then
   `git commit -m "eval/<system>/<bug id>: M<N> <outcome>  success=<true|false>"`, then
   `git push origin main`. One milestone per commit.
